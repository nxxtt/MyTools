# Roadmap de Features

## Facil (horas-dias)

### SQL Injection Scanner
Módulo standalone com techniques: error-based, blind, time-based, union, boolean.
Hoje só existe dentro do attackaudit como sub-check.
Payloads em data/web/sqli.yaml.

### Command Injection Scanner
OWASP Top 10. Testa parametros GET/POST/headers com payloads de comando.
Detecta por timing, erro, ou reflexao no response.

### CSRF Scanner
Testa ativamente a presenca de tokens CSRF em forms.
Hoje so detecta passivamente se o campo csrf_token existe (dentro do attackaudit).
Testes ativos: remover token, reutilizar token, trocar metodo.

### LFI/RFI Scanner
Diferente do path traversal (que ja existe).
Foca em inclusao de arquivos locais/remotos via parametros como ?file=, ?page=, ?include=.

### Batch Scanner
mytools-batch targets.txt -- roda modulo(s) contra N alvos de um arquivo.
Uteis para CI/CD e scans em escala.

## Medio (dias)

### Subdomain Takeover
Deteccao de dangling CNAME apontando para servicos nao reclamados.
S3, CloudFront, Azure, Heroku, GitHub Pages, etc.
Alto valor para recon externo.

### Login Brute Force / Credential Testing
Teste de rate limit em endpoints de autenticacao.
Credential stuffing, password spray, account lockout detection.
Nao existe hoje no projeto.

### Cloud Bucket Enumeration (S3/GCP/Azure)
Enumeracao de buckets S3, GCP Cloud Storage, Azure Blob.
Listagem, ACL, politicas, objetos.
Zero cobertura atual.

### REST API Fuzzer
Fuzzing generico de APIs REST: parameter pollution, metodos HTTP inesperados,
version enum (/v1, /v2, /v3), autenticacao bypass, HATEOAS discovery.
So GraphQL tem cobertura dedicada hoje.

### Client-side Prototype Pollution
Modulo atual so testa server-side (reflexao em response).
DOM-based PP detectaria sinks reais no browser (lodash, jQuery, express).

## Avancado (semanas)

### Ruby + .NET + Node.js Deserialization
3 plataformas grandes sem cobertura de desserializacao.
Ruby Marshal.load, .NET BinaryFormatter/ViewState, Node.js node-serialize.

### Handlebars + Go + Blade + Razor SSTI
4 engines populares nao testadas no modulo de SSTI atual.
Handlebars (Node), Go text/template, Blade (PHP), Razor (.NET).

### HTTP/2 Downgrade Smuggling + CL.0
O modulo atual so cobre CL.TE / TE.CL classico.
CL.0 (Content-Length ignorado pelo front-end) e h2c smuggling sao tecnicas modernas nao cobertas.

### CDN-Specific Cache Poisoning
Cloudflare, Akamai, Fastly tem behavior de cache key especifico.
X-Forwarded-Port/Proto/Scheme, True-Client-IP, CF-Connecting-IP.
Nao testado hoje.

### Mobile API Testing
Nada existe para Android/iOS/React Native/Flutter.
Teste de API pinning, armazenamento local, OAuth2 implicit flow.

## Complexo (meses)

### HTML Report Generator
CLI output e rico mas sem relatorio visual.
Template HTML com findings, severidade, evidencias, timeline.
Comparacao entre scans (diff de resultados).

### Headless Browser (Playwright)
Para testes em JS/SPA. DOM clobbering real, XSS em contexto renderizado,
crawler de paginas com JavaScript, captura de screenshots.

### Plugin System
Arquitetura para terceiros escreverem modulos sem editar o core.
Hook discovery, schema de metadados, isolated namespace.

### Dependency Scanner
Detecta bibliotecas front-end (npm, CDN) e back-end via fingerprint.
Compara com banco de CVEs (tipo retire.js / WPScan lite).

### CMS Fingerprinting
WordPress, Joomla, Drupal, Magento detection.
Versao especifica, plugins, temas, users.

### Email Spoofing Ativo
Hoje e so analise DNS (SPF/DKIM/DMARC).
Envio de email de teste + verificacao de entrega validaria as politicas de verdade.

### WebSocket Fuzzer
Modulo atual testa protocolo (frames, opcodes, compression).
Fuzzing de payload real em mensagens WebSocket.
